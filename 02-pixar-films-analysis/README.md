# Pixar Films Performance Analysis

## Project Overview
This project analyzes the performance of Pixar films using SQL.  
It explores box office success, return on investment (ROI), critical ratings, director performance, and Academy Award results.

## Business Questions Answered
- Which Pixar films performed best at the box office?
- Which films delivered the highest return on investment (ROI)?
- How do Pixar films perform on critical and audience ratings?
- Which directors are associated with the highest total box office?
- How successful are Pixar films at the Academy Awards?

## Dataset
- **Source**: Maven Analytics – Pixar Films Dataset
- **Tables Used**:
  - pixar_films
  - box_office
  - academy
  - pixar_people
  - public_response
  - genres

## Tools Used
- SQL Server (Data analysis)
- Microsoft Excel (Initial exploration)
- Power BI (Dashboard – coming next)

## Key Insights
- **Inside Out 2**, **Incredibles 2**, and **Toy Story 4** are among the highest-grossing films.
- **Toy Story** has one of the highest ROIs due to its relatively low budget.
- Average ratings are strong (Rotten Tomatoes ~88, IMDb ~7.5).
- Top directors by total box office: Brad Bird, Andrew Stanton, John Lasseter, and Pete Docter.
- WALL-E received the highest number of Oscar nominations.
