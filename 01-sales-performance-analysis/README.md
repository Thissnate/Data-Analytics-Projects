# Sales Performance Analysis – Superstore Dataset

## Project Overview
This project analyzes sales performance of a retail superstore using SQL.  
The goal is to identify top-performing regions, categories, products, and customer segments, as well as highlight areas with low or negative profitability.

## Business Questions Answered
1. What is the overall sales and profit performance?
2. Which region generates the highest sales and profit?
3. Which product categories and sub-categories perform best?
4. What is the monthly sales trend?
5. Which products generate the highest sales?
6. How do different customer segments perform?

## Dataset
- **Source**: Sample Superstore Dataset (public)
- **Records**: 9,994 rows
- **Key Columns**: Order Date, Region, Category, Sub-Category, Product Name, Sales, Quantity, Discount, Profit, Segment

## Tools Used
- Microsoft Excel (Data cleaning & preparation)
- SQL Server (Data analysis)
- Power BI (Dashboard – coming next)

## Key Insights
- **West region** has the highest sales and profit.
- **Technology** is the top category by sales.
- **Office Supplies** has the highest profit margin.
- Some high-selling products (especially certain Tables, Machines, and Bookcases) have negative profit.
- **Consumer** segment contributes the highest sales and has the largest number of customers.

## Files in this Project
- `data/` → Cleaned dataset
- `sql/analysis_queries.sql` → All SQL queries used in the analysis
- `powerbi/` → Power BI dashboard (to be added)

## How to Run the Queries
1. Import the cleaned dataset into SQL Server.
2. Open `analysis_queries.sql`.
3. Execute the queries one by one.
